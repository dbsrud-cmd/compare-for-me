# 나 대신 비교해줘

사용자가 붙여 넣은 설명과 사진·스크린샷을 실제 Gemini API로 비교하는 한국어 웹서비스입니다. 목적·예산·중요 조건을 반영하고, 어려운 용어를 별표 버튼으로 쉽게 설명합니다.

**현재 상태:** 로컬에서 텍스트 및 이미지 비교에 성공했습니다. GitHub 주소는 소스 저장소이며, 인터넷에서 AI를 사용하는 서비스 주소는 Workers 무료 배포 및 비밀 설정 후 발급됩니다. 가짜 AI 결과나 규칙 기반 추천을 실제 AI처럼 표시하지 않습니다.

## 기능

- 비교 대상 2~4개, 대상별 텍스트 및 이미지 최대 2개
- PNG·JPEG·WebP, 이미지당 2MB, 전체 6개·6MB 제한
- 입력 목적·예산·우선순위에 따른 비교표, 장단점, 조건부 추천
- 원문 인용 근거, 누락 정보 및 추가 확인 질문
- RAM 등 용어의 뜻·비유·중요한 이유·확인할 점과 난이도 선택
- 용어 추가 질문, 조건 변경 재비교, 동일 입력의 현재 탭 결과 재사용
- 입력·이미지·분석 결과를 DB나 브라우저 영구 저장소에 보관하지 않음

## 실행

Node.js가 있는 환경에서 별도 라이브러리 설치 없이 실행합니다.

```sh
npm start
```

`http://127.0.0.1:8765`를 엽니다. Windows 비밀 설정 파일은 `%LOCALAPPDATA%\CompareHelper\.dev.vars`에 직접 생성합니다.

```text
GEMINI_API_KEY=직접_등록할_비밀키
ACCESS_PASSWORD=영문숫자_16자_이상_이용암호
FREE_TIER_CONFIRMED=false
```

Gemini 프로젝트가 결제 미연결 Free Tier임을 확인했을 때만 마지막 값을 `true`로 설정하고 서버를 재시작합니다. 실제 키는 채팅이나 GitHub에 올리지 마세요. 사이트의 이용 암호 칸은 API 키를 넣는 곳이 아닙니다.

## 무료 배포

[Cloudflare Workers 무료 배포 안내](DEPLOY.md)를 따라 서버와 정적 파일을 함께 배포합니다. **GitHub Pages 단독으로는 AI 서버를 실행할 수 없습니다.**

```sh
npm run build
```

공개 정적 파일 5개만 `deploy/public`에 준비합니다. `worker.mjs`와 `wrangler.jsonc`가 서버 배포 설정입니다. API 키와 이용 암호는 Worker Secret으로 등록합니다. 로컬 비밀 파일을 업로드하지 않습니다.

## 확인한 범위

- 자동 테스트 23개 통과: 입력·용량·형식·원문 인용·JSON 검증, 인증·한도·키 오류·시간 초과·혼잡 오류 처리
- 실제 Gemini 텍스트 비교 및 스크린샷·JPEG 합성 설명 이미지 비교 성공
- 브라우저 비교표와 용어 설명 대화상자 표시 확인
- 합성 이미지는 테스트 자료이며 실제 상품 사진 전체의 인식 정확성을 보장하지 않음
- 무료 API에서 503 혼잡 및 연결 시간 초과가 간헐적으로 발생함
- 용어 추가 질문의 실제 호출은 연결 시간 초과로 미검증. 인터넷 배포·모바일 전체 검증도 아직 미완료

## 비용 및 개인정보

고정 모델은 `gemini-3.1-flash-lite`입니다. 2026-10-16 공식 가격표의 Standard Free Tier 입출력 무료 조건을 확인했습니다. 계정별 지원과 한도는 AI Studio에서 확인해야 합니다. 유료 모델 대체·자동 재시도·검색 도구는 사용하지 않습니다.

앱 제한은 인스턴스당 분당 3회·하루 30회이며 전역 한도가 아닙니다. `FREE_TIER_CONFIRMED`는 운영자 확인 표시이고 계정 과금 상태를 자동 검증하지 않습니다. 결제·유료 플랜을 활성화하지 마세요.

무료 Gemini에 전송한 자료가 제공자 제품 개선에 쓰일 수 있으므로 개인정보·민감 자료를 입력하지 마세요. 추천은 제공된 자료에 따른 참고 판단이며 구매 전 상태와 조건을 직접 확인해야 합니다.
